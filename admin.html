Вход для владельца

Нужен токен GitHub с доступом к репозиторию test-trainer. Он хранится только на этом устройстве и никуда не отправляется, кроме GitHub.

Как получить токен
  1. Откройте готовую форму токена: название, срок и доступ к файлам уже заполнены.
  2. В блоке Repository access выберите Only select repositories, затем в списке — test-trainer.
  3. Нажмите Generate token внизу, скопируйте токен и вставьте сюда.

Не получается? Классический токен: галочка public_repo уже стоит — нажмите Generate token.
