# Тренажёр тестов

Веб-версия тренажёра для iPhone: вопросы из JSON — один ответ, несколько ответов, выпадающий список, порядок, текстовый ответ, кейсы; звёздочки, поиск, свои тесты с баллами.

**Открыть:** ссылка GitHub Pages этого репозитория (Settings → Pages).

На iPhone: открыть в Safari → «Поделиться» → «На экран „Домой“». Работает без интернета.
Свой JSON: ☰ → «Мои файлы» → «Загрузить JSON» (хранится только на телефоне, другим не виден).

## Файлы курсов (видят все)

Удобнее всего — через админку: `admin.html` (в тренажёре: поиск «админ» или ☰ → Настройки → Админка).
Вход — токен GitHub с доступом Contents: Read and write к этому репозиторию; он хранится только на устройстве владельца.
Админка сама коммитит файл в `data/<курс>/` и обновляет `data/sets.json`.

Вручную: положите `*.json` в папку курса `data/1` … `data/6` и выполните:

```
git pull
python3 собрать.py
git add -A && git commit -m "Обновил вопросы" && git push
```

## Счётчик «сейчас в сети»

Firebase Realtime Database: адрес базы в `FIREBASE_DB` — в `app.html` и в `admin.html` (одинаковый).
Посетитель пишет только случайный анонимный номер и время, без имён.

`app.html` — само приложение; `index.html` и `sw.js` собирает `собрать.py`.
