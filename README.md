# Тренажёр тестов

Веб-версия тренажёра для iPhone: вопросы из JSON — один ответ, несколько ответов, выпадающий список, порядок, текстовый ответ, кейсы; звёздочки, поиск, свои тесты с баллами.

**Открыть:** ссылка GitHub Pages этого репозитория (Settings → Pages).

На iPhone: открыть в Safari → «Поделиться» → «На экран „Домой“». Работает без интернета.
Свой JSON: ☰ → «Мои файлы» → «Загрузить JSON» (хранится только на телефоне, другим не виден).

## Файлы курсов (видят все)

Удобнее всего — через админку: `admin.html` (в тренажёре: поиск «админ» или ☰ → Настройки → Админка).
Вход — токен GitHub с доступом Contents: Read and write к этому репозиторию; он хранится только на устройстве владельца.
Админка сама коммитит файл в `data/<курс>/` и обновляет `data/sets.json`.

Вручную: положите `*.json` в папку курса `data/1` … `data/6` и выполните:

```
git pull
python3 собрать.py
git add -A && git commit -m "Обновил вопросы" && git push
```

## Счётчик «сейчас в сети»

Firebase Realtime Database: адрес базы в `FIREBASE_DB` — в `app.html` и в `admin.html` (одинаковый).
Гость пишет только случайный номер и время; у вошедшего в аккаунт рядом стоит его uid.

## Аккаунты

После 5 ответов сайт просит зарегистрироваться: имя пользователя и пароль.
- Пароли хранит Firebase Authentication. Вход идёт по случайной служебной почте `…@users.example.com`: на неё ничего не отправляется.
- `logins/<имя>` — кому принадлежит имя. Имя сравнивается без учёта регистра и пробелов, «ё» = «е». Занять чужое имя не дают правила базы.
- `users/<uid>` — имя, курс, когда заходил. Сменить имя можно один раз, это тоже проверяют правила.
- В админке аккаунты можно блокировать и удалять. Заблокированный видит «Доступ закрыт». Удаление освобождает имя.
- Вход через Google: кнопка «Продолжить с Google» (видна, если заполнен `GOOGLE_CLIENT_ID` в `app.html`). Google возвращает человека на сайт, Firebase проверяет вход, и человек один раз выбирает имя пользователя. В `logins` у такого аккаунта стоит `g:<uid>`.
- Пароль не восстановить: почты нет. Если человек забыл пароль, удалите его аккаунт в админке, и он зарегистрируется заново.

Нужно для работы:
- `FB_API_KEY` (Web API Key из Firebase → Project settings) в `app.html` и `admin.html`. Пока ключа нет, аккаунты выключены.
- Правила из `firebase.rules.json` (в них уже стоит UID администратора). Их вставляют в Firebase → Realtime Database → Rules → Publish.

`app.html` — само приложение; `index.html` и `sw.js` собирает `собрать.py`.
